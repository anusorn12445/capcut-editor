🇹🇭 Botnoi Voiceต้องมี Token

เชื่อมต่อ Subtitle (Whisper)

🌐 ในเครื่อง (on-device)ฟรี
Whisper รันในเบราว์เซอร์ (tiny/base/small) — เลือกระดับจาก dropdown ข้างปุ่ม Subtitle ไม่ต้องมี key
⚡ OpenAI Whisperต้องมี API Key

จาก platform.openai.com → API keys
🚀 Groq Whisperต้องมี API Key

สมัครฟรีที่ console.groq.com → API Keys
🎙️ ElevenLabs Scribeต้องมี API Key

จาก elevenlabs.io → Profile → API Keys
